# FairHire AI 💼

FairHire AI is an AI-powered hiring fairness analyzer.

## 🚀 Features
- AI-based hiring decision explanation
- Bias detection system
- Real-time analysis
- Clean UI

## 🌐 Live Demo

## 🎯 Purpose
To eliminate bias in hiring and make decisions transparent and fair.
